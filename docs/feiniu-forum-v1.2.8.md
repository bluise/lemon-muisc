## 详细更新说明

### 下载：试听时长检测

- 对比音源实际时长与搜索结果中的完整时长  
- 相差较多（如完整 4 分钟却只有约 1 分钟）→ **取消下载**，提示试听时长，可换源重试  
- 下载页可筛选失败任务，并批量「重试试听失败」

### 试听：自动换源 / 换平台

- 检测到短片段 → 先换同平台其它已激活音源  
- 仍不行 → 按歌名+歌手在其它平台搜索匹配，验到完整时长再播  
- 底栏 / 全屏显示当前平台名  
- 多次样本后，设置里可看到该音源哪些平台多为试听、哪些较完整

### 睡眠定时

- 底栏月亮按钮循环：15 / 30 / 45 / 60 / 90 分钟，到点停止播放

### 本地库查重

- 按「标题 + 歌手」分组；可复制路径  
- **删除文件**：从磁盘永久删除（同组至少保留一份）

### 账号备份

- 设置 → 我的账号 → 导出 / 导入歌单、收藏、最近播放与个人界面设置  
- 可选「合并导入歌单」

## 主要功能一览（本版仍支持）

说明：日常使用里，**下载**与**标签编辑**是核心整理链路；音乐库与试听用于浏览与听歌。

### 下载（核心）

- 搜索 / 发现多选批量下载；音质与降档策略确认  
- 任务队列、进度、暂停 / 继续、移出列表 / 删文件  
- 同名文件询问 / 跳过 / 覆盖；按歌手或专辑分组保存  
- 内嵌封面 / 歌词；独立 `.lrc`  
- **试听时长拦截**与换源重试（本版加强）

### 标签编辑（核心）

- 扫描本地目录，批量编辑 ID3 / FLAC  
- 按文件名匹配网络元数据；封面 / 歌词补全  
- 保存更稳；可同步到正在播放

### 搜索 / 发现 / 试听

- 酷我、酷狗、QQ、网易云、咪咕等多平台检索与推荐歌单  
- 底栏播放器、频谱、全屏歌词、试听列表、后台播放  
- **短片段自动换源换平台**、睡眠定时、平台徽章（本版）

### 音乐库

- 本地扫描、智能歌单、复制网络歌单、同步本地标识  
- 热更新、专辑 / 风格浏览  
- **查重与删文件**（本版）

### 设置与账号

- 多音源（落雪 / 澜音）、按用户启用、健康度标注  
- 多用户、邮件找回、个人 / 共享下载目录  
- **备份迁移**、主题配色、日活统计开关（本版相关）

## 安装与更新

### 方式一：应用中心（若已同步上架）

在应用中心直接更新到 v1.2.8。

### 方式二：手动安装 FPK

从 GitHub Release 下载对应架构：

| 架构 | 文件名 |
|------|--------|
| x86 | `lemon-music-1.2.8-x86.fpk` |
| ARM | `lemon-music-1.2.8-arm.fpk` |

应用中心 → **手动安装** → 选择 FPK。

### 首次使用提示

1. 首次打开创建**管理员账号**（可选邮件）  
2. **设置 → 音源管理** 导入并激活音源（可同时多个）  
3. **设置 → 文件路径** 配置音乐库与下载目录  
4. 默认端口：**7983**  
5. 卸载不会删除你指定的音乐库 / 下载目录中的音频
