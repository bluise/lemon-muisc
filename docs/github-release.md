# 柠檬音乐 v1.2.8

## 更新

### 下载

- 加强「试听时长」检测：实际时长明显短于完整曲则取消下载并提示，可换源重试
- 下载任务状态筛选、「重试试听失败」

### 试听与音源

- 短片段自动换同平台音源，再换其它平台搜同名曲
- 底栏显示当前平台名；音源健康度按平台累计（多为试听 / 部分平台试听）

### 其它

- 睡眠定时、本地库查重（可删磁盘文件）、账号备份迁移
- 日活上报配置不进仓库，打包时本机注入

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.8-x86.fpk`
- `lemon-music-1.2.8-arm.fpk`
