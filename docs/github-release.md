# 柠檬音乐 v1.2.12

## 更新

### 发现页大升级

- **歌单 / 排行榜 / 新歌首发 / 新碟首发** 分区展示，支持「更多」进入完整列表
- 分区可左右滑动翻页；曲目支持加入试听列表、收藏、加入歌单、选音质下载
- 封面渐进加载：先出列表再补封面，排行榜首屏更快

### 试听与播放

- 播放栏 / 全屏播放器可为当前曲目一键下载（选音质）
- 播放链路过期或缓存异常时自动重建管道，减少「浏览器无法播放该音频格式」误报

### 其它

- 延续 v1.2.11：手机端搜索 / 发现曲目列表排版修复

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.12-x86.fpk`
- `lemon-music-1.2.12-arm.fpk`
