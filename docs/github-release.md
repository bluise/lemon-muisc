# 柠檬音乐 v1.2.9

## 更新

### 标签编辑（本版重点）

- 窄屏 / 手机自适应：工具栏换行、卡片列表、底部编辑抽屉
- **手动检测**：按文件名搜索对比内嵌标签，标黄不正确字段；可一键采用建议（含封面 / 歌词）
- **按文件名重设**：勾选后批量按文件名重新匹配并保存
- 匹配 / 手动检测支持 **暂停、继续、停止**
- **有限并发**匹配（默认 3 路，设置 → 音源管理可调 1–6）
- 保存安全：「保存当前」只写正在编辑的一首；批量应用需确认，避免全选误覆盖

### 查重

- 优先按文件名解析的歌名 / 歌手分组，减少错误内嵌标签导致的误判

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.9-x86.fpk`
- `lemon-music-1.2.9-arm.fpk`
