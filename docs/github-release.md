# 柠檬音乐 v1.2.10

## 更新

### 搜索 / 歌单

- 支持搜索歌单并打开详情；加载进度条
- 可将平台歌单导入到音乐库歌单
- 酷狗封面：按专辑补全；歌单曲目缺封面时回落到歌单封面

### 下载

- **真 FLAC 校验**：拒绝 QQ 等返回的假 flac（实为 MP3）
- 选无损默认 **不降档**；批量确认框可选自动降级 / 最低音质
- 音质菜单只显示音源实际返回的档位（如仅 128 则只显示 128）
- 酷我识别 **FLAC Hi-Res**（新 N_MINFO）
- 同名文件「跳过」：不误报音乐库新增，并从下载列表移除
- 添加下载后列表实时出现（无需手动刷新）

### 体验

- 应用内确认弹窗，替代浏览器原生 confirm / alert
- 标签「按文件名重设」仅作用于勾选文件；匹配 / 检测可暂停停止（延续）

### 日活统计（作者侧）

- 看板增强：当前在线、按版本、久未上线、建议（需同步上传站点 PHP）

本版仍为原生独立应用（不依赖 Docker），依赖应用中心 Node.js v22。

## 安装包

- `lemon-music-1.2.10-x86.fpk`
- `lemon-music-1.2.10-arm.fpk`
