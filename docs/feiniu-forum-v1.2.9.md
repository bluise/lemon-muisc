大家好，**柠檬音乐**（飞牛应用中心显示名）发布 **v1.2.9**。

相对 **v1.2.8**，这一版重点打磨 **标签编辑** 与 **查重**：

1. **标签页手机 / 窄屏自适应**（卡片列表 + 底部编辑抽屉，工具栏不再挤没）  
2. **手动检测**：按文件名搜索对比内嵌标签，标黄不正确字段，可一键采用（含封面 / 歌词）  
3. **按文件名重设全部** + **有限并发**（设置里可调 1–6 路）  
4. **保存防护**：避免全选后误把同一首歌信息写进全部文件  
5. **查重更准**：优先按文件名解析歌名 / 歌手，减少错误标签误报  

v1.2.8 的试听时长拦截、自动换源换平台、睡眠定时、查重删文件、账号备份等能力全部保留。

应用仍为**原生 FPK**，不依赖 Docker，运行依赖应用中心 **Node.js v22**。

**GitHub Release**：https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.9  
**仓库地址**：https://github.com/jia070310/lemon-muisc

## 详细更新说明

### 标签编辑：自适应

- 电脑窗口缩窄：工具栏换行，试听 / 加入队列列可 sticky 贴边  
- 手机：卡片式文件行（封面、歌名、缺失标记、操作按钮始终可见）  
- 点歌曲 → **底部抽屉**编辑，不再滚到页面外才看得见编辑区  

### 手动检测

- 按**文件名**搜索（支持歌手-歌名、歌名-歌手两种方向）  
- 与当前内嵌标题 / 歌手 / 专辑对比  
- 不一致 → 字段**标黄**，显示建议值  
- 「全部采用建议」会拉取并写入 **封面 + 歌词** 等，再点「保存当前到文件」落盘  

### 按文件名重设全部

- 对当前文件夹全部文件：按文件名重新匹配网络信息并**直接保存到磁盘**  
- 适合标签批量写错、或想整夹按文件名重刷标签的场景  
- 点击前会弹出确认  

### 并发与限流

- 批量匹配默认 **3 路并行**，约可快近 3 倍  
- 设置 → 音源管理 →「标签匹配并发」可调 **1–6**  
- 过高可能被 QQ / 网易等接口限流，建议先用 3，失败多了再调低  

### 保存防护（重要）

- 右侧 **「保存当前到文件」**：**只写正在编辑的那一首**  
- 要把同一份表单套到多首：先点 **「应用到选中」**（会确认）→ 再点顶部 **「保存全部修改」**  
- 避免全选后误把一首歌的信息写进整夹文件  

### 查重更准

- 分组优先用文件名解析出的歌名 / 歌手  
- 减少「文件名不同、但内嵌标签被写成同一首歌」时的误判

## 主要功能一览（本版仍支持）

说明：日常使用里，**下载**与**标签编辑**是核心整理链路；音乐库与试听用于浏览与听歌。

### 下载（核心）

- 搜索 / 发现多选批量下载；音质与降档策略确认  
- 任务队列、进度、暂停 / 继续、移出列表 / 删文件  
- 同名文件询问 / 跳过 / 覆盖；按歌手或专辑分组保存  
- 内嵌封面 / 歌词；独立 `.lrc`  
- **试听时长拦截**与换源重试  

### 标签编辑（核心 · 本版加强）

- 扫描本地目录，批量编辑 ID3 / FLAC  
- 匹配缺失 / 匹配选中；**手动检测**；**按文件名重设全部**  
- 封面 / 歌词补全；**可调并发**；保存更安全  
- 手机端可用  

### 搜索 / 发现 / 试听

- 酷我、酷狗、QQ、网易云、咪咕等多平台检索与推荐歌单  
- 底栏播放器、频谱、全屏歌词、试听列表、后台播放  
- **短片段自动换源换平台**、睡眠定时、平台徽章  

### 音乐库

- 本地扫描、智能歌单、复制网络歌单、同步本地标识  
- 热更新、专辑 / 风格浏览  
- **查重与删文件**（分组更准）  

### 设置与账号

- 多音源（落雪 / 澜音）、按用户启用、健康度标注  
- **标签匹配并发**  
- 多用户、邮件找回、个人 / 共享下载目录  
- **备份迁移**、主题配色、日活统计开关

## 安装与更新

### 方式一：应用中心（若已同步上架）

在应用中心直接更新到 v1.2.9。

### 方式二：手动安装 FPK

从 GitHub Release 下载对应架构：

| 架构 | 文件名 |
|------|--------|
| x86 | `lemon-music-1.2.9-x86.fpk` |
| ARM | `lemon-music-1.2.9-arm.fpk` |

应用中心 → **手动安装** → 选择 FPK。

### 首次使用提示

1. 首次打开创建**管理员账号**（可选邮件）  
2. **设置 → 音源管理** 导入并激活音源（可同时多个）；可按需调整「标签匹配并发」  
3. **设置 → 文件路径** 配置音乐库与下载目录  
4. 默认端口：**7983**  
5. 卸载不会删除你指定的音乐库 / 下载目录中的音频
