大家好，柠檬音乐（飞牛应用中心显示名）发布 v1.2.12。

这一版重点在「发现」页：不只是粘贴歌单链接，还把歌单、排行榜、新歌首发、新碟首发做成分区浏览；试听时也能从播放栏直接下载当前曲目。

应用仍为原生 FPK，不依赖 Docker，运行依赖应用中心 Node.js v22。

GitHub Release：https://github.com/jia070310/lemon-muisc/releases/tag/v1.2.12
仓库地址：https://github.com/jia070310/lemon-muisc

---

【本版亮点】

1. 发现页分区：歌单 / 排行榜 / 新歌 / 新碟，点「更多」进完整列表
2. 分区可左右滑动翻页；曲目可加入试听列表、收藏、歌单、选音质下载
3. 封面渐进加载，首屏更快出来
4. 播放栏、全屏播放器支持当前曲目一键下载
5. 播放链路异常时自动恢复，减少「浏览器无法播放该音频格式」一类误报

【安装 / 更新】

1. 到 GitHub Release 下载对应架构：
   - lemon-music-1.2.12-x86.fpk
   - lemon-music-1.2.12-arm.fpk
2. 飞牛应用中心 → 手动安装 / 更新 FPK
3. 依赖应用中心 Node.js v22（未装会随应用一并安装）
4. 首次或权限变更时，在访问权限里确认音乐库 / 下载目录

---

【给新人的一句话】

先在「发现」或「搜索」找歌试听，满意了点下载落到 NAS；再用「标签编辑」把歌名、歌手、封面、歌词整理好。

请仅用于个人已合法授权的音乐资源管理，遵守当地法律与各平台服务条款。
